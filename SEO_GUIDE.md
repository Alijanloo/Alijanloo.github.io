# SEO Optimization Guide for Ali Janloo's Blog

This document outlines the SEO optimizations implemented and additional steps to improve Google search visibility, especially for Persian searches using "علی جانلو".

---

## 🚀 Steps to Boost SEO

### A. **Google Search Console Setup** (IMPORTANT!)

1. **Verify Your Site:**
   - Go to [Google Search Console](https://search.google.com/search-console)
   - Add property: `https://alijanloo.github.io`
   - Verify using HTML tag method:
     - Copy the verification code
     - Add to `_config.yml` under `webmaster_verifications.google`
   
2. **Submit Sitemap:**
   ```
   https://alijanloo.github.io/sitemap.xml
   ```

3. **Request Indexing:**
   - In Search Console, use "URL Inspection" tool
   - Submit your homepage and key pages
   - Request indexing for each

### B. **Create Persian Content**

To rank for "علی جانلو", create content with Persian keywords:

**Option 1: Add Persian Section to About Page**
```markdown

در حال حاضر به عنوان مهندس یادگیری ماشین در شرکت پارس‌تک مشغول به کار هستم.

**حوزه‌های تخصصی:**
- پردازش زبان طبیعی (NLP)
```

**Option 2: Create a Persian Blog Post**
Create: `_posts/2025-10-19-introduction-persian.md`

### C. **Google Business Profile** (Optional but Recommended)

1. Create a Google Business Profile
2. Link to your website
3. Add your Persian name as alternate name
4. This helps with Knowledge Graph and local searches

### D. **Backlink Strategy**

Create backlinks with anchor text "علی جانلو":

1. **LinkedIn Profile:**
   - Ensure your LinkedIn has link to your blog
   - Use "علی جانلو" in your LinkedIn name/headline

2. **GitHub Profile:**
   - Add blog link to GitHub profile README
   - Mention "علی جانلو" in bio

3. **Academic Profiles:**
   - Google Scholar (if you have papers)
   - ResearchGate
   - ORCID

4. **Social Media:**

### E. **Content Creation for Persian Queries**

Write blog posts that naturally include:
- "علی جانلو" in author byline

- Topics relevant to Iranian tech community

Example post ideas:

- "My Journey in AI (سفر من در هوش مصنوعی) - by علی جانلو"

### F. **Internal Linking**

Ensure all blog posts link to your About page, which contains "علی جانلو"

## 💡 Pro Tips

1. **Consistency is Key:**
   - Use "Ali Janloo | علی جانلو" format consistently across all platforms

2. **Content Quality:**
   - Write valuable, unique content
   - Regular posting schedule (aim for 2-4 posts/month)

3. **Technical SEO:**
   - Ensure fast loading times
   - Mobile-responsive (Chirpy theme already handles this)

   - Encourage shares and comments
   - Respond to comments if enabled
   - Build a community

5. **Persian SEO:**
   - Persian content has less competition
   - Target "علی جانلو هوش مصنوعی" as a long-tail keyword
   - Consider creating Persian versions of popular posts
